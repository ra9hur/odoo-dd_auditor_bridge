# DD Auditor Bridge (Odoo)

**D&D Auditor Bridge** adds a **Verify D&D Charges** button to Vendor Bills in Odoo,
providing single sign-on to the D&D Auditor Web Application via a shared HMAC-signed token.

> **Important:** This module is a **free connector** that requires an active **paid tier
> subscription** to the D&D Audit Web Application in order to function.

- **Odoo version:** 18.0 (branch `18.0`)
- **License:** LGPL-3
- **Author:** Raghu Ramarao
