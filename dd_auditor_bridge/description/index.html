D&D Auditor Bridge

Seamless Single Sign-On from Odoo Vendor Bills to the D&D Auditor Web Application

Adds a "Verify D&D Charges" button to your Vendor Bills (Invoices). Clicking it opens the D&D Auditor Web Application, securely authenticated against your Odoo session via a shared HMAC-signed token. No data is stored locally in Odoo — this module is a thin, stateless connector.

Features

  • One-click "Verify D&D Charges" button on Vendor Bill forms.
  • Automated Single Sign-On using an HMAC-SHA256 signed token.
  • Per-company admin toggle to enable or disable the integration.
  • Configurable App URL and shared HMAC secret.
  • No additional data stored in Odoo.

Configuration

  1. Install the module.
  2. Go to Settings → General Settings → D&D Auditor.
  3. Enable the D&D Auditor Integration toggle.
  4. Set the App URL to your D&D Auditor API base URL (e.g. https://dd-auditor-api.onrender.com).
  5. Enter the HMAC Secret. It must match the ODOO_HMAC_SECRET configured in the D&D Auditor backend.
  6. Save your settings.

Usage

Open a Vendor Bill (Incoming Invoice). In the header, click the Verify D&D Charges button. A new tab will open the D&D Auditor application, logged in securely on your behalf.

Free Module — Paid Subscription Applies

Important: This module is a free connector that requires an active paid tier subscription to the D&D Audit Web Application in order to function. The Odoo module itself is free, but access to the connected audit service is provided under a separate paid subscription.
